# Fotos da Feira de Tecnologia

Coloque aqui as fotos do estande do EcoPulse com estes nomes:

- `estande-01.jpg` — visitantes interagindo com o jogo
- `estande-02.jpg` — equipe DEVassos no estande
- `estande-03.jpg` — o jogo rodando na tela 2, ao lado do dashboard

Enquanto os arquivos não existirem, a galeria some e aparece um aviso
discreto no lugar. Ao adicionar as imagens, elas entram automaticamente
na página `docs/index.html` (seção EcoPulse Desafio).

Recomendações: JPG, lado maior entre 1600 px e 2000 px, até ~400 KB
cada. Evite rostos de terceiros sem autorização.
